# 🔐 Password Bot (Генератор и проверка паролей)

Telegram-бот на Python для создания надежных паролей и оценки сложности уже существующих.

## 🛠 Технологии
* **Python 3**
* **pyTelegramBotAPI** (для работы с Telegram)
* **Random** и **String** (встроенные модули Python для генерации)

## ⚙️ Функционал
* `/start` — краткая инструкция по командам.
* `/password` — генерирует случайный пароль длиной 16 символов (буквы верхнего и нижнего регистра, цифры, спецсимволы).
* `/check [пароль]` — анализирует пароль и выдает результат:
  * 🟢 Отличный (длина от 12 символов, есть цифры и заглавные буквы).
  * 🟡 Нормальный (с подсказками, чего не хватает).
  * 🔴 Слабый (с рекомендациями по улучшению).

## 🚀 Как запустить локально
1. Установите библиотеку: `pip install pyTelegramBotAPI`
2. Вставьте свой токен от `@BotFather` в переменную `TOKEN` в файле `password_bot.py`.
3. Запустите скрипт: `python password_bot.py`

## 💡 Пример использования
* Отправь `/password` -> Бот выдаст: `aB3$x9LmP!q2Rz7W`
* Отправь `/check qwerty` -> Бот ответит: `🔴 Слабый пароль! • Слишком короткий (нужно 12+) • Добавь цифру • Добавь заглавную букву`
